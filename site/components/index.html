Component catalogue

Shared component definitions grouped by structural, content, scenario, interaction, support and legacy purpose. Every component carries a visible status — text and colour, never colour alone.

Current implementation: live previews and class names show the existing ISQ Rise expression of each component. The component purpose, anatomy and accessibility contract are reusable; the .isq-* namespace and visual theme are not.
