Support component

Button

Primary, secondary and light calls to action.

core Current implementation: ISQ Rise Version introduced: 1.0.0 Platforms: Rise Owner: Design and development steward

ISQ Rise implementation preview

Rendered with the governed ISQ production Rise CSS
Open resource↗

Light background shown; verify against a tinted or dark surface where the component is used that way in course.

Use when / avoid when

Use when

  • A single clear action per area — one primary action, optionally one secondary.

Avoid when

  • Never use vague labels such as “Click here” — label the destination or outcome.

Anatomy

  • Label text
  • Optional icon (aria-hidden)

Variants

isq-button--primaryisq-button--secondaryisq-button--light

States

defaulthoverfocus-visibledisabled

Responsive behaviour

Full-width on narrow screens where it is the primary action in a stacked layout.

Accessibility

  • Use a real
  • Visible focus ring at sufficient contrast.
  • External links state their destination behaviour via aria-label.
