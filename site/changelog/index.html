Changelog

Records added, changed, fixed, deprecated and removed items per release, from this catalogue's first version.

v0.2.0September 2026
Added
  • Implementation directory separating the core system from organisational and platform expressions.
  • Independent Schools Queensland implementation hub and dedicated ISQ foundations.
  • Course Applications layer with an explicit source-authority and qualification-evidence contract.
  • Primary navigation entry for the implementation-independent Learning Design model.
Changed
  • Renamed the product and site identity to eLearning Design System.
  • Replaced ISQ-derived site chrome with a neutral documentation palette and typography.
  • Reframed component pages as reusable contracts with the existing ISQ Rise code shown as a named implementation.
  • Moved Rise, Connect & Learn, Storyline and media guidance beneath the ISQ implementation while preserving earlier routes.
  • Changed Learning Design reuse scope from isq-wide to system-wide.
Fixed
  • Removed organisation-specific foundations and source hierarchy from the neutral core.
  • Removed side-highlight callout styling from the documentation interface.
v0.1.0July 2026
Added
  • Initial live reference site: Overview, Foundations, Learning patterns, Component catalogue, Platform implementation (Rise, Connect & Learn, Storyline), Imagery & media, Resources, Governance, Changelog.
  • Component data model and JSON source covering foundations, 11 learning patterns and 21 components.
  • Client-side search index and filterable component catalogue.
  • A first specification for the previously undocumented Self-assessment component.
Changed
  • Divider status reconciled from Document 2's "Restricted" to the confirmed lifecycle status Experimental.
  • Role split adopted as the canonical name for the previously unsettled Role comparison / Role split naming.
Fixed
  • Grid, Band and Process added to the component data model after being found in the production CSS and Document 2's prose but missing from its technical class index.
