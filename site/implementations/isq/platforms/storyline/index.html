Storyline

A controlled extension point, not a commitment to support every tool. Storyline guidance is added only where a recurring delivery need is proven.

When Storyline is justified

Selective guidance where complex interaction or simulation is required — cases the Rise authoring environment cannot adequately express. No source material for this stream has been supplied yet; this page is a placeholder ready to accept content.

How it consumes shared foundations

In principle: the same colour roles, typography and spacing tokens as Rise and Connect & Learn, applied through Storyline's own theme and slide-master mechanisms rather than a shared stylesheet. This has not been implemented or tested.

Boundaries

Not yet defined. Do not build a Storyline course against this page until interaction conventions, launch/completion behaviour and visual tokens have been confirmed and documented here.
