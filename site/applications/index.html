Course applications

Where the system meets real course work

Applications use the core system through a named implementation. They supply evidence, constraints and refinements without becoming the reusable system themselves.

Source authority remains separate: approved course documents govern learner-facing copy. The design system governs presentation, interaction, accessibility and reusable technical behaviour.
