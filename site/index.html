ISQ eLearning Design System

One design language, defined once, consumed everywhere.

Strategy · foundations · learning patterns · components · platform implementation · governance

This is the live operational reference for ISQ digital learning design and development. It connects learning design, visual design, interaction design and technical delivery across Articulate Rise, Connect & Learn and future ISQ digital learning products. Rise is the system's first mature implementation — this is not a Rise-only component library.
